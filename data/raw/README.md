# data/raw — input files

Nothing here is generated by this repository; everything else under `data/` is rebuilt from these files by
`python run.py`. `python run.py --steps inputs` checks each file against the SHA-256 checksums in
[`../manifest.tsv`](../manifest.tsv). A fresh download of a live database (UniProt REST) may not match the checksum.

`data/external/` (TF labels and gene ages) is small and tracked in git: `local_mapping/` is built from
`uniprot/uniprot_ensembl_xref_raw.tsv` by `scripts/build_local_annotations.py` (the default); `hpc_snapshot/` holds
the labels from the cluster run (used with `TFIDR_ANNOTATIONS=hpc_snapshot`).
